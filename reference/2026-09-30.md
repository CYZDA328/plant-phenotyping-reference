# 2026-09-30

- **标题**：A-Occ-Plant: Plant Occluded Point Cloud Completion via Amodal Segmentation
- **来源**：Plant Phenomics（Science Partner Journal）
- **发布日期**：2026年6月23日在线发表，收录于2026年9月刊（第8卷第3期，article 100240）
- **概述**：针对田间植株点云因叶片相互遮挡导致的结构缺失问题，该研究提出将3D点云转换为多视角2D图像、利用非模态分割（amodal segmentation）补全被遮挡区域后再重建三维结构的新方法，显著提升了复杂遮挡场景下器官级表型点云的完整性与提取精度。
- **链接**：https://www.sciencedirect.com/science/article/pii/S2643651526000774

- **标题**：PhenoRob-P: An autonomous robotic system for high-throughput phenotyping of potted plants
- **来源**：Plant Phenomics（Science Partner Journal）
- **发布日期**：2026年6月6日在线发表，收录于2026年9月刊（第8卷第3期，article 100232）
- **概述**：该研究提出一套搭载六自由度机械臂与模块化末端传感器的自主机器人系统，可在温室环境中对盆栽作物进行近距离高通量数据采集，实现每小时处理逾千株植物的表型测量效率，株高等性状估计与人工测量高度吻合。
- **链接**：https://www.sciencedirect.com/science/article/pii/S2643651526000695

- **标题**：PhenoIntel: A Lifecycle-Aligned Multi-Agent Web Application for Verified, Accessible Plant Phenotype Analysis
- **来源**：arXiv (2608.27999)
- **发布日期**：2026年8月31日
- **概述**：该工作构建了由九个专职智能体协同、覆盖从图像采集、模型选择、推理到报告生成全流程的多智能体网页平台，旨在为不具备机器学习背景的植物科学家提供可验证、易用的表型分析自动化工具。
- **链接**：https://arxiv.org/abs/2608.27999
