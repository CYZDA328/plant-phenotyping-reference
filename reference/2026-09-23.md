# 2026-09-23

- **标题**：Evaluating Mesh Reconstruction Methods for Crop Phenotyping
- **来源**：arXiv (2609.16926)
- **发布日期**：2026-09-15
- **概述**：针对偏远种植地点专家难以现场开展作物表型鉴定的问题，系统评测了7种基于多视角图像的三维网格重建管线（涵盖NeRF、2DGS、PGSR、GGGS等），从保真度与一致性两方面对比其在作物数字化重建中的表现，结果显示GGGS、PGSR与2DGS重建的网格质量更优，为作物三维表型重建方法选型提供了实证依据。
- **链接**：https://arxiv.org/abs/2609.16926

- **标题**：Zero-Shot 3D Plant Organ Segmentation with SAM3 and Semantic NeRFs
- **来源**：arXiv，已被ECCVW 2026接收
- **发布日期**：2026年9月上旬
- **概述**：提出一种无需人工标注、无需按物种微调的零样本三维植物器官分割流程，将文本提示驱动的SAM3分割结果与语义神经辐射场（Semantic NeRF）结合，仅凭多视角RGB图像与类别名称列表即可生成带语义标签的三维点云；在秋海棠测试集上达到92.6% mIoU，并在覆盖十种植物的新数据集上取得平均0.856 mIoU的效果。
- **链接**：https://arxiv.org/abs/2609.07724

- **标题**：PlantC2USeg: Cross-Scale Consistent Pre-Training for Few-Shot Unified Plant Point Cloud Segmentation
- **来源**：arXiv (2609.02860)
- **发布日期**：2026-09-02
- **概述**：针对植物三维点云分割中不同尺度、不同物种间分布差异导致模型难以泛化的问题，提出跨尺度一致性预训练框架PlantC2USeg，用于少样本场景下的统一植物点云分割，降低了分布偏移下的模型适配成本，为可扩展的植物表型分析与可迁移三维表征学习提供了新方法。
- **链接**：https://arxiv.org/abs/2609.02860
