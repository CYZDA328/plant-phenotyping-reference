# 2026-09-03

- **标题**：PhenoRob-P: An autonomous robotic system for high-throughput phenotyping of potted crops
- **来源**：Plant Phenomics
- **发布日期**：2026年9月
- **概述**：针对温室盆栽作物场景下过道狭窄、GNSS信号缺失、花盆排布不规则及单株数据可追溯性差等难题，提出模块化自主机器人系统PhenoRob-P，集成双轮差速底盘、LiDAR-视觉融合导航、单盆目标定位与六自由度机械臂实时位姿补偿，实现盆栽作物的高通量多视角近距离成像；温室验证中连续扫描模式吞吐量达520盆/小时、多视角精细检测模式187盆/小时，定位误差控制在30毫米以内，并在小麦上完成了干旱胁迫及复水恢复过程的时序表型验证。
- **链接**：https://www.sciencedirect.com/science/article/pii/S2643651526000695
