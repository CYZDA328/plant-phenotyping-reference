# 2026-08-31

- **标题**：PhenoIntel: A Lifecycle-Aligned Multi-Agent Web Application for Verified, Accessible Plant Phenotype Analysis
- **来源**：arXiv 预印本（cs），arXiv:2608.27999
- **发布日期**：2026-08-28
- **概述**：提出了一个"生命周期对齐"的多智能体网页平台PhenoIntel，将植物表型分析的完整机器学习流程拆分给九个专职智能体（从图像采集到模型选择、推理与报告），并通过阶段间独立校验和统一的共享数据结构来避免现有对话式表型分析工具中"分析失败被误报为有效结果、统计检验不检查前提假设、预测无不确定性估计"等可靠性问题。
- **链接**：https://arxiv.org/abs/2608.27999

- **标题**：Denoising-Aware Temporal Point Cloud Completion for 3D Crop Architecture Recovery and Phenotypic Trait Extraction
- **来源**：arXiv 预印本（cs），arXiv:2608.28343
- **发布日期**：2026-08-28
- **概述**：针对高通量表型中植物生长阶段3D重建缺乏完整几何真值数据集的问题，提出了程序化生成的合成数据集SynthCrop4D（含可控噪声、遮挡与完整植物几何），并设计了"空间去噪+时序点云补全"两阶段流程：先用去噪模块去除激光扫描点云的结构性伪影，再用自适应时序PoinTr模型结合前一生长阶段(t-1)信息重建当前阶段(t)因自遮挡缺失的区域，服务于3D作物结构恢复与表型性状提取。
- **链接**：https://arxiv.org/abs/2608.28343
