# 2026-09-27

- **标题**：Evaluating Mesh Reconstruction Methods for Crop Phenotyping
- **来源**：arXiv (2609.16926)
- **发布日期**：2026年9月
- **概述**：该研究系统评测了7种主流3D网格重建方法（含高斯泼溅类GGGS、PGSR、2DGS等）在作物三维表型重建任务上的保真度与一致性，发现GGGS、PGSR和2DGS在定量指标和视觉效果上均优于其他方法，为远程作物数字化表型提供了方法选型参考。
- **链接**：https://arxiv.org/abs/2609.16926

- **标题**：PlantC2USeg: Cross-Scale Consistent Pre-Training for Few-Shot Unified Plant Point Cloud Segmentation
- **来源**：arXiv (2609.02860)
- **发布日期**：2026年9月
- **概述**：针对植物点云器官级分割依赖大量标注数据的问题，该工作提出跨尺度一致性预训练框架，通过限制信息的解码策略防止“捷径式”重建，实现跨物种、跨传感条件下仅需少量样本即可稳定泛化的少样本分割能力。
- **链接**：https://arxiv.org/abs/2609.02860

- **标题**：RootQuantV2: Adapting a Vision Foundation Model for Root-Trait Regression from Minirhizotron Imagery
- **来源**：arXiv (2609.25567)
- **发布日期**：2026年9月
- **概述**：该研究将视觉基础模型适配用于微根管（minirhizotron）图像的根系性状直接回归预测，无需人工描摹掩膜，并可复用以往专有软件导出的历史标量数据进行训练，为田间根系高通量表型提供了可扩展的自动化方案。
- **链接**：https://arxiv.org/abs/2609.25567
