# 2026-09-14

- **标题**：PlantC2USeg: Cross-Scale Consistent Pre-Training for Few-Shot Unified Plant Point Cloud Segmentation
- **来源**：arXiv (2609.02860)
- **发布日期**：2026-09-02
- **概述**：提出跨尺度一致性预训练框架PlantC2USeg，用于面向育种场景的少样本统一植物点云分割：通过跨尺度特征对齐与限制信息解码策略防止重建捷径，实现跨物种（大豆、烟草、番茄、高粱、玉米等）及跨传感条件下的稳定少样本泛化与器官级性状量化，在大豆点云数据上取得91.91%的语义IoU与94.62%的实例mWCov，显著降低了标注与再训练成本。
- **链接**：https://arxiv.org/abs/2609.02860
