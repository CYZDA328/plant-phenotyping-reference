- **标题**：Denoising-Aware Temporal Point Cloud Completion for 3D Crop Architecture Recovery and Phenotypic Trait Extraction
- **来源**：arXiv (2608.28343)
- **发布日期**：2026-08-28
- **概述**：提出两阶段点云处理管线，先对激光扫描原始点云做空间去噪，再用自适应时序PoinTr模型利用前一生长阶段信息补全当前阶段因自遮挡缺失的区域，并配套构建了可控噪声/遮挡的合成数据集SynthCrop4D，用于评测作物4D点云重建与性状提取方法。
- **链接**：https://arxiv.org/abs/2608.28343

- **标题**：PlantOmicsGWAS: An end-to-end, reproducible framework for plant genome-wide association and genomic prediction using linear and pan-genome references
- **来源**：bioRxiv
- **发布日期**：2026-08-16
- **概述**：发布了一套端到端、可复现的植物全基因组关联分析（GWAS）与基因组预测框架，基于GEMMA实现贝叶斯稀疏线性混合模型的多性状关联分析，并支持FaST-LMM、随机森林、XGBoost等机器学习方法作为对照基准，同时兼容线性参考基因组与泛基因组，服务于表型-基因型协同分析场景。
- **链接**：https://www.biorxiv.org/content/10.64898/2026.08.16.745120v1
