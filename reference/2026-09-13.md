# 2026-09-13

- **标题**：PlantC2USeg: Cross-Scale Consistent Pre-Training for Few-Shot Unified Plant Point Cloud Segmentation
- **来源**：arXiv (2609.02860)
- **发布日期**：2026-09-02
- **概述**：提出跨尺度一致性预训练框架PlantC2USeg，用于少样本统一植物点云分割：通过跨尺度特征对齐学习和限制性解码策略防止重建捷径，实现跨物种（大豆、烟草、番茄、高粱、玉米等）和跨传感条件的稳定少样本泛化，并配合统一微调策略进一步降低适配开销，在大豆点云上取得较高的语义IoU和实例分割精度。
- **链接**：https://arxiv.org/abs/2609.02860
