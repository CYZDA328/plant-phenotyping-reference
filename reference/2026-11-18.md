# 2026-11-18

- **标题**：DBGCN: Dual-branch Graph Convolutional Network for organ instance inference on sparsely labeled 3D plant data
- **来源**：Plant Phenomics（KeAi/Elsevier，article 100188，Vol. 8, Issue 2）；东华大学信息科学与技术学院、北京农林科学院团队；EurekAlert"Dual-branch graph convolutional network maps plant organs from sparse labels"近期专题报道（news-releases/1151487，与下一条wheat canopy论文同批，发布ID明显晚于10月24日那一批的1149xxx系列，属于近期新一轮Plant Phenomics报道）
- **发布日期**：期刊论文PubMed标注在线发表于2026年3月9日；EurekAlert/Newswise对该研究的集中报道为近期新一批次（约2026年11月上中旬）
- **概述**：提出DBGCN双分支图卷积网络，将稀疏标注的3D植株点云转为图结构，一个分支采用固定邻接结构（类GCNII）捕捉整体植株架构，另一分支在逐层演化的特征空间中动态搜索邻居以适应局部变化，仅需极少量标注即可实现器官实例级分割，在多个数据集上超过GCN、GCNII、GAT、PSegNet等基线模型，为降低3D植株点云标注成本提供了新思路。
- **链接**：https://www.eurekalert.org/news-releases/1151487 （论文：https://www.sciopen.com/article/10.1016/j.plaphe.2026.100188 ；代码：https://github.com/chinazhouzhaoyi/DBGCN）

- **标题**：Looking sideways helps drones read wheat canopies（基于多角度斜视高光谱成像的小麦冠层结构反演）
- **来源**：Plant Phenomics；南京农业大学团队；EurekAlert报道"Looking sideways helps drones read wheat canopies"（news-releases/1151005，与上一条DBGCN论文同批次报道）
- **发布日期**：论文Newswise转载标注在线发表于2026年2月12日；EurekAlert集中报道为近期新一批次（约2026年11月上中旬，与DBGCN同批）
- **概述**：团队构建结合BRDF模型与预测学习的多角度斜视无人机高光谱成像框架，发现相比传统垄断的正下方（nadir）拍摄，适当倾斜视角（约15°-45°）能揭示被遮挡的冠层结构信息，在两个生长季（2023年342个品系、2024年560个品系）的小麦材料上反演叶面积指数（LAI）、叶倾角分布参数（LIDFa）及植被覆盖度（FCover），其中LiDense-RossHotspot组合与机载BRF实测值拟合最佳（R²≈0.88），为无人机高通量表型采集的视角优化提供了实证依据。
- **链接**：https://www.eurekalert.org/news-releases/1151005
